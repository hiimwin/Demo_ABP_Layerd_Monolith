
Layer Contracts 
   |--> Chứa các thư mục như là DTO, Interface Service
   |--> Chứa các thông tin phân quyền cho user 
Layer Application
   |--> Chứa các thư mục như là Service để triển khai từ Layer Contracts 
   |--> Chứa các thư mục để config Automapper
Layer Domain
   |--> Chứa các Entity
   |--> Chứa các thư mục như là SeedData
Layer EntityFrameworkCore
   |--> Chứa các file cấu hình của DBContext
Layer Shared
   |--> Chứa các file như là enum 
   |--> Chứa file en.json

_ Các lệnh cần sử dụng 
  + dotnet run --migrate-database
  + abp install-libs
  + dotnet ef migrations add Created_Book_Entity   (Cần triền khai trên Layer EntityFrameworkCore )
  + dotnet ef database update  (Cần triền khai trên Layer EntityFrameworkCore )
  + Ngoài ra có thể chạy layer DbMigrator  (Ưu tiền cái này)

  _ Cần Học Thêm 
  + Coi them openid Connect   (https://abp.io/docs/latest/modules/openiddict)
  + Coi them phan quyen voi permission(Done), policy (Done), Features
